# Werkbon Qvantum

Deze repository beheert de governance, contracten, besluiten en het bewijs voor de digitale werkbon van Qvantum.

GPT/Chat is architect, reviewer en besluitvormer. Codex is technische inspecteur, ophaler, uitvoerder en validator. Work is uitsluitend het specialistische kanaal wanneer een connector aantoonbaar meerwaarde heeft. Git is de leidende bron.

Start iedere Chat-, Work- en Codex-sessie bij [ACTUEEL - Werkbon Qvantum projectstatus](docs/current/ACTUEEL%20-%20Werkbon%20Qvantum%20projectstatus.md).

Technische acties vinden alleen plaats vanuit een expliciet vrijgegeven werkpakket. Secrets horen nooit in deze repository.
